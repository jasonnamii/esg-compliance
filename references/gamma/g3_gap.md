# Γ3 갭분석 — 3등급 방법

## 등급 정의
| 등급 | 의미 | 조치 |
|------|------|------|
| 🟢 충족 | 요구수준 만족 | 유지·증빙 보존 |
| 🟡 미흡 | 일부 충족·문서/운영 부족 | 보완(기한 설정) |
| 🔴 결격 | 미구축·법정의무 위반 | 즉시 구축(최우선) |

## 우선순위 (적색 중에서도)
1. 법정 의무 위반(처벌 직결) → 즉시
2. 게이트 차단(IPO·실사 탈락) → 게이트 일정 역산
3. 모범사례 미달(가점 상실) → 여력 시

## 출력
항목별 요구수준 → 현행 → 등급 → 게이트 영향 → 보완조치 → 기한.
